# prabh-portfolio

Single-page portfolio (static HTML/CSS/JS).

## Local preview

Open `index.html` in a browser, or run:

```bash
npx --yes serve .
```

## Deploy on Vercel

1. Push this repo to [github.com/Prabh101726/prabh-portfolio](https://github.com/Prabh101726/prabh-portfolio).
2. [Vercel](https://vercel.com) → **Add New** → **Project** → Import **prabh-portfolio**.
3. Settings:
   - **Framework Preset:** Other (or “Static Site”)
   - **Build Command:** *(leave empty)*
   - **Output Directory:** *(leave empty — site root)*
4. Deploy. Your site will be live at `*.vercel.app`; add a custom domain under **Settings → Domains** if you want.

No environment variables required for this static page.
